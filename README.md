Лендинг вымышленного аукциона нестандартных лотов. Проектная работа, выполненная в рамках обучения вёрстке. Главная цель — сверстать макет из Figma с использованием семантического HTML и современных возможностей CSS, применяя подход Pixel Perfect.

## Технологии

* **HTML5** (семантическая разметка)
* **CSS3** (Grid, Flexbox, кастомные свойства, позиционирование)
* **Методология БЭМ** (Блок-Элемент-Модификатор) для именования CSS-классов
* **Шрифты:** Raleway (подключены локально через `@font-face`)
